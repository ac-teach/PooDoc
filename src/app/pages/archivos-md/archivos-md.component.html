04

Archivos Markdown (.md) para la Entrega de Documentación

Estructura estandarizada de entregables técnicos en la raíz del repositorio.

Además del código fuente, el proyecto debe contener tres archivos Markdown (.md) obligatorios en la raíz, los cuales consolidan la investigación, las fichas conceptuales y el análisis técnico del estudiante.

quiz CUESTIONARIO.md

Contiene las 28 preguntas del cuestionario diagnóstico respondiendo formalmente cada apartado: Java/POO, Persistencia y JavaFX/MVC.

Campos requeridos:
• Pregunta N°
• Respuesta investigada
• Explicación con propias palabras
• Ejemplo de aplicación en LibraryApp
menu_book GLOSARIO.md

Fichas técnicas individuales para un mínimo de 25 conceptos clave vinculados directamente con las clases del proyecto.

Campos por Ficha:
1. Término técnico
2. Definición formal
3. Definición en mis palabras
4. Ubicación en el código
5. Ejemplo práctico & problema que resuelve
analytics COMPONENTES.md

Bitácora de investigación y análisis arquitectónico de cada clase, interfaz y archivo FXML reconstruido.

Campos por Componente:
• Nombre de la clase / paquete
• Capa arquitectónica (MVC/DAO)
• Responsabilidad única
• Dependencias directas
• Diagrama/Flujo del dato
