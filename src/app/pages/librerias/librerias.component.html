Configuración del Proyecto con Librerías

Gestión manual de dependencias (.jar)

En esta modalidad de trabajo, la gestión de dependencias externas (Driver JDBC de MySQL y SDK de JavaFX) se realiza incorporando físicamente los archivos binarios .jar en el directorio del proyecto y configurándolos manualmente en el IDE y en las instrucciones de compilación/ejecución.

folder_zip Estructura física del directorio `lib/`

Crea una carpeta llamada lib en la raíz del proyecto e incluye los siguientes conectores y módulos: 

LibraryApp/
├── lib/
│   ├── mysql-connector-j-8.3.0.jar    # Driver JDBC de MySQL
│   ├── javafx.base.jar                # JavaFX Base Module
│   ├── javafx.controls.jar            # JavaFX UI Controls
│   ├── javafx.fxml.jar                # JavaFX FXML Loader
│   ├── javafx.graphics.jar            # JavaFX Graphics
│   ├── javafx.media.jar               # JavaFX Medios
│   ├── javafx.swing.jar               # JavaFX Componentes Swing
│   └── javafx.web.jar                 # JavaFX Elementos Web
├── src/                               # Código fuente Java (.java)
└── bin/                               # Bytecode compilado (.class)

settings Instrucciones de configuración en IDEs principales

En NetBeans IDE: 1. Clic derecho en el proyecto > Properties > Libraries.
2. En la pestaña Classpath, haz clic en Add JAR/Folder.
3. Navega a la carpeta lib/, selecciona todos los archivos .jar y presiona Open.
4. En la pestaña Run, añade los VM Options para JavaFX: --module-path "C:\javafx-sdk-21.0.11\lib" --add-modules javafx.controls,javafx.fxml

terminal Compilación y Ejecución manual por Línea de Comandos (CLI) si es necesario

Si compilas directamente desde la terminal, utiliza las siguientes instrucciones especificando el classpath y los módulos de JavaFX:

1. Compilación: 
javac -cp "lib/*" --module-path lib --add-modules javafx.controls,javafx.fxml -d bin src/org/ac/model/*.java src/org/ac/dao/*.java src/org/ac/controller/*.java
2. Ejecución: 
java -cp "bin:lib/*" --module-path lib --add-modules javafx.controls,javafx.fxml org.ac.Main
